Wi-Fi はどういう原理で使えるのか

2026-06-14

一言でいうと: Wi-Fi は、データ（0と1）を電波（電磁波）の変化に変換して空中に飛ばし、受け取った側が元のデータに戻す無線通信。ケーブルの代わりに「電波」を線にしているだけ。

1. データは電波に「乗せて」運ばれる

パソコンやスマホが扱うのは 0 と 1 のデジタルデータ。これをそのまま飛ばすことはできないので、ルーター（アクセスポイント）の中の無線チップが、データに合わせて電波の波の形を細かく変化させる。これを変調（modulation）と呼ぶ。

  • 送信側: データ → 電波の波形を変化させて空中へ放射
  • 受信側: 電波の波形の変化を読み取って → データに復元

波の「振幅」や「位相」を組み合わせて、1回の波で複数ビットを表現する（QAM という方式）。これにより1秒間に大量のデータを運べる。

2. 周波数帯（2.4GHz と 5GHz / 6GHz）

電波には周波数があり、Wi-Fi は主に3つの帯域を使う。家庭でよく聞く「2.4GHz / 5GHz」はこれ。

帯域特徴
2.4GHz遠くまで届く・壁に強い。ただし電子レンジやBluetoothと干渉しやすく遅くなりがち
5GHz速い・干渉が少ない。ただし障害物に弱く距離が短い
6GHz (Wi-Fi 6E/7)さらに空いていて高速。対応機器が必要

「家の奥だと2.4GHz、ルーターの近くなら5GHz」のように使い分けると安定しやすい。

3. チャンネルと混信

各帯域はさらに「チャンネル」という細かい区画に分かれている。近所のWi-Fiと同じチャンネルが重なると混信して遅くなる。最近のルーターは空いているチャンネルを自動で選ぶが、遅いときは手動でチャンネルを変えると改善することがある。

4. スマホがWi-Fiに「繋がる」までの流れ

  1. 発見: アクセスポイントは自分の名前（SSID）を電波で定期的に発信している。スマホはそれを拾って一覧表示する。
  2. 認証: パスワード（事前共有鍵）で本人確認。正しければ接続を許可される。
  3. 暗号化: 以降の通信は WPA2 / WPA3 で暗号化され、電波を傍受されても中身は読めない。
  4. IPアドレス取得: ルーターから DHCP で IP アドレスを割り当てられ、ようやくネットへ通信できる状態になる。

5. Wi-Fi はインターネットそのものではない

Wi-Fi は「家の中の無線の足回り」にすぎない。

よくある誤解だが、Wi-Fi 自体はインターネットではない。スマホ ↔ ルーター間を無線でつなぐ技術であって、ルーターから先（インターネット）は光回線などの有線でプロバイダに繋がっている。だから「Wi-Fiマークは立っているのにネットが見れない」が起きる＝無線区間はOKだが、その先の回線側で問題がある状態。

まとめ

  • Wi-Fi = データを電波に乗せて飛ばす無線通信。ケーブルの代わり。
  • 周波数帯（2.4/5/6GHz）で「届く距離」と「速さ」のトレードオフがある。
  • 繋がる流れは「発見 → 認証 → 暗号化 → IP取得」。
  • Wi-Fiはルーターまで。その先のインターネットは別物。
